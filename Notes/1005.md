## Kivetelkezeles

### Kivetel - Exception

- fatasideju hiba megszakitja a program menetet
- ha nincs lekezelve a program leall, hibauzenetet ir ki
- a kivetel osztalyok mind az Exception osztalyboil szarmaznak (oroklodnek)

---

### try-catch

``` c#
try // ha jo semmi nem tortenik
{
    <kod, ami hibazhat>
    1 Kivetel? (int.Parse)
    2
    3
}
catch // ha rossz ez az intezkedes
{
    <mi tortenjen hiba eseten>
    ex.Message - hiba szoveges leriasa
    ex.GetType - kivetel pontos tipusa
}
finaly //  elhagyhato
{
    <mindig lefut>
}

```

- egy try blockhoz tobb catch is tartozhat
  - kulonbozo kivetel tipusokra
- a catch agakat a specifikustol az altalanos fele erdemes sorba rakni
- a finaly jellemzoen eroforrasok felszabadaitasara hasznaljuk (file, db kapcsolat lezarasa)
- akkor is lefut ha try/catch return volt

#### Gyakori kiveteltipusok

- DevidedByZeroException --> nullaval valo osztas
- IndexOutOfRangeException --> ervenytelen index tomb/lista
- NullReferenceException --> null objektumon probalunk metodust hivni
- FormatException --> pl. sikertelen string -> szam atalakitas
- ArgumentException / ArgumentNullException --> ervenytelen parameter
- InvalidOperationException --> az objektum jelenlegi allapotaban nem vegezheto el a muvelet
