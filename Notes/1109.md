# Git alapműveletek, README és .gitignore

## Fájlállapotok

Egy file lehet:

- **untracked** - Git - még - nem koveti
- **tracked / unchanged** - kovetett de meg nem modosult
- **modified** - modosult az utolso commit ota
- **staged** - a modositas bekerult a kovetkezp commit elokeszitett tartalmaba

### git status

A legfontosabb diagnosztikai parancs ezekkel kapcsolatban:

``` bash
git status
```

Erdemes lehet a muveletek elott hasznalni ha nem vagyunk biztos az allapotaban

### git diff

``` bash
git diff
```

A `git diff` alaphelyzetben a working dir es a staging area kozotti kulonbseget mutatja

### git log

Commit tortenet

#### Teljes nezet

``` bash
git log
```

#### Tomor nezet

``` bash
git log --oneline
```

#### Agakkal kesobb kulonosen hasznos

``` bash
git log --oneline --graph --decorate --all
```

#### A commit hash

``` text
b3ff8990880f8f0as1aa089891a8918
```

A roviditett valtozata: `b3ff899` ami csak az elso karaktereket tartalmazza

A commit hash segitsegevel konkret commitokra tudunk hivatkozni
